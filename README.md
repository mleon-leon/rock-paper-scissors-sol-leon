# Piedra, Papel o Tijera

Juego de consola de Piedra, Papel o Tijera desarrollado en Python.

## Autora

Sol León

## Tecnologías utilizadas

- Python 3
- PyCharm
- Git y GitHub

## Reglas del juego

- El jugador elige piedra, papel o tijera.
- La computadora genera una opción aleatoria.
- En caso de empate, no se asignan puntos.
- Gana el jugador que consiga primero 2 puntos.
- Al finalizar una partida, el jugador puede elegir si desea jugar nuevamente.

## Funcionalidades

- Valida la opción ingresada por el jugador.
- Genera una opción aleatoria para la computadora.
- Determina el ganador de cada ronda.
- Lleva el puntaje del jugador y de la computadora.
- Finaliza la partida cuando un jugador alcanza 2 puntos.
- Permite iniciar una nueva partida.

## Cómo ejecutar el programa

1. Abre el proyecto en PyCharm.
2. Ejecuta el archivo `main.py`.

También puedes ejecutarlo desde una terminal con el siguiente comando:

```bash
python main.py
```
